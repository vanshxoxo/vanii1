# vanii1

[![Open in Bolt](https://bolt.new/static/open-in-bolt.svg)](https://bolt.new/~/sb1-e7k43ebm)

Little Loom storefront. The app uses Supabase for commerce data and ImageKit for product and storefront media delivery. Start with [the setup guide](supabase/SETUP.md), [database schema overview](supabase/SCHEMA.md), and [deployment checklist](DEPLOYMENT_CHECKLIST.md). No service credentials are committed; use browser-safe Supabase values in `.env.local` and keep private provider keys server-side.
